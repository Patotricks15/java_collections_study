# Java Exercises: Collections, Comparators, and Iterators

This repository contains a collection of practical exercises developed to explore how lists, sorting, and collection navigation work in Java.

## 🚀 Completed Exercises

### 1. [Library System Sorting](./library_system_sorting/)
- **Objective:** Explore the `Comparable` and `Comparator` interfaces to organize objects.
- **Highlights:** 
  - Implementation of **natural order** by title.
  - Creation of **custom comparators** (by author, year, and pages) using Method References.
  - Use of `Iterator` for safe data filtering.

### 2. [User Access History](./users_access_history/)
- **Objective:** Use efficient data structures to manage temporary logs.
- **Highlights:**
  - Use of `LinkedList` to maintain a history limited to the last 5 accesses.
  - Demonstration of insertion at the top and automatic removal of old records ($O(1)$).
